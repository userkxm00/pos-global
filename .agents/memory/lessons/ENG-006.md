- **PROJECT:** pos-global
- **PHASE:** F2.02
- **CATEGORY:** Review Triage / Scope

- **STATUS:** ACTIVE

## 1. Problem
An automated AI reviewer (Codex) commented on PR #65 (F2.02 Categories, Brands, Manufacturers) suggesting that foreign key columns `brand_id` and `manufacturer_id` should be added to the `products` table.

## 2. Root Cause
The automated reviewer analyzed the taxonomy domain in isolation without consulting the project backlog (`BACKLOG.md`), which explicitly designated `Product -> Brand` and `Product -> Manufacturer` relations to a future milestone (F2.17).

## 3. Why Checks Missed It
Automated review bots lack full multi-phase architectural roadmap awareness unless cross-checked against project specifications.

## 4. Evidence
- `BACKLOG.md` lines 114–116 explicitly allocate `Product -> Brand/Manufacturer` linkage to milestone F2.17.
- Phase F2.01 (`products` table) is already merged and protected. Adding columns in F2.02 would violate phase encapsulation.

## 5. Correct Fix
Triaged the review finding against `BACKLOG.md` and `SCHEMA.md`, determined the comment was out-of-scope and premature for F2.02, and protected merged phase F2.01 code from modification.

## 6. Regression Test
Verified that F2.02 taxonomy models (categories, brands, manufacturers) operate independently with zero regressions to F2.01 products.

## 7. Prevention Rule
**RULE 1.2:** Never implement reviewer suggestions blindly. Always verify whether suggested fields, tables, or relations belong to the active phase or a scheduled future phase in `BACKLOG.md`.
